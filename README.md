# Pirates Invasion

Jogo para fins educacionais aplicando conceitos de motores de fisica e uso da p5.js em um jogo com a tematica de invasao pirata

---
## 📚 Aprendizados
- Motores de fisica
- p5.js


## ⚙️ Funcionalidades
- Use as setas do teclado para mirar o canhao para cima e para baixo
- e use a seta para baixo para atirar


## 🛠️ Stack

- JavaScript
- HTML5
- CSS3
- P5.js

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone 
https://github.com/gabrielbentoo/pirates-invasion
```

2. Abra o arquivo `index.html` em seu navegador.
